Export Music – אתר תדמית
===========================

מה יש בתיקייה:
  index.html    – האתר עצמו (עמוד אחד)
  hero2.jpg     – התמונה הראשית
  s1–s14.jpg    – תמונות התלמידים עם התעודות (הסרט הנע)
  e1–e13.jpg    – תמונות הבוגרים באירועים
  og.jpg        – התמונה שמופיעה כששולחים את הקישור בוואטסאפ/פייסבוק
  favicon.svg   – האייקון הקטן בלשונית הדפדפן

איך מחברים קישורי תשלום (כשיהיו):
  1. פותחים את index.html בעורך טקסט.
  2. מחפשים data-pay=""  (מופיע פעמיים – פעם למסלול הפרטי ופעם לכיתתי).
  3. מדביקים בין המירכאות את קישור דף התשלום של כל מסלול, למשל:
       data-pay="https://pay.example.co.il/abc123"
  4. שומרים ומעלים מחדש.
  כל עוד השדה ריק – הכפתור בחלון ההרשמה פותח וואטסאפ עם הודעה מוכנה.

העלאה לאוויר: מעלים את כל הקבצים (לא רק את index.html) לאותה תיקייה ראשית ב-GitHub.
